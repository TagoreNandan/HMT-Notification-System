# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately using one of these options:

1. **GitHub Security Advisories** (preferred): open a [private vulnerability report](https://github.com/YOUR_ORG/product-availability-monitor/security/advisories/new) on this repository (available once the repo is published on GitHub).
2. **Email:** contact the maintainer directly at `[your-security-email@example.com]` with a description of the issue and steps to reproduce.

Please include:

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

We aim to acknowledge reports within **72 hours** and will work with you on a fix before public disclosure when appropriate.

## Scope

This policy covers the application code in this repository (API, auth, notification dispatch, scraping adapters). It does not cover third-party services (Resend, Railway, ntfy, target e-commerce sites).

## Supported versions

Only the latest release on the default branch receives security updates.
